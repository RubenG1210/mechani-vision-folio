# Grant Union Robotics

Build a clean, minimalist portfolio website using HTML, modern CSS, and JavaScript.

DESIGN & STYLE:

- Style: Minimalist, clean, and modern layout.

- Color Palette: Clean neutral background with deep dark green accent colors (e.g., emerald/forest green) for links, buttons, and subtle hover states.

- Structure: Multi-page layout with a shared, sticky header and footer across all pages. Top navigation links: Home, Projects, Blog, About, Contact.

PAGE 1: HOME PAGE (Intro Focus)

- Minimalist landing page focused purely on the intro—no heavy project showcases here.

- Bold text introduction highlighting:

  - Grant Union High School student

  - Sacramento / 916 native

  - Aspiring Mechatronics Engineer (aiming for high-level robotics like Boston Dynamics)

- Call-to-action buttons leading visitors to explore the "Projects" page or "Contact" page.

PAGE 2: PROJECTS (/projects.html)

- Clean, structured grid or card layout showcasing 5 key projects:

  1. Wake-A-Time — In-progress haptic wrist alarm device.

  2. Home Harvest — ESP32 automated indoor plant grower (1st place MESA prelims & regionals, State Finalist).

  3. MESA Coding Solutions — 1st place prelims, 3rd place regionals.

  4. Solar Car — MESA Sacramento solar car race build.

  5. Grant Union FRC Team Initiative — Actively working to establish and found the school's FIRST Robotics Competition team.

- Tech stack/category tags for each project (e.g., ESP32, Embedded C++, Hardware, Leadership, Sensors).

PAGE 3: BLOG / LOGS (/blog.html)

- Clean list of the 4 blog posts:

  - "The Science Behind Wake-A-Time"

  - "From Seed to State: The Home Harvest MESA Journey"

  - "Why Grant Union Needs an FRC Robotics Team" (discussing the vision behind starting it)

  - "What Mechatronics Means to Me"

- Each post title should click through to its own clean reading page (e.g., /blog/wake-a-time.html).

PAGE 4: ABOUT (/about.html)

- Personal background as a Sacramento student heading into Grant Union High School.

- Future goals in mechatronics and advanced hardware engineering.

- Skills badges: Embedded C++, ESP32, Sensors, Robotics.

- Minimal vertical timeline highlighting MESA competition achievements and current milestones (including working on founding the FRC team).

PAGE 5: CONTACT & FOOTER (/contact.html)

- Minimalist contact form (Name, Email, Message).

- Direct links to social profiles (include these in both the contact section and site-wide footer):

  - GitHub: https://github.com/RubenG1210

  - Instagram: https://www.instagram.com/orangutan_ruben
